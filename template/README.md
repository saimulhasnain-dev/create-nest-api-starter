# {{name}}

NestJS API generated by `create-nest-api-starter`.

```sh
cp .env.example .env
npm install
npm run dev      # http://localhost:3000/health and /users
npm test
npm run build && npm start
```

Included: validated config (`src/config.ts`), global `ValidationPipe` (whitelist + forbid unknown fields), one error shape for all failures (`src/all-exceptions.filter.ts`), graceful shutdown hooks, a sample `users` module (DTO validation, 404/409 handling) and jest + supertest tests.
